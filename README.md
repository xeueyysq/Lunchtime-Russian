# Lunchtime Cozy Create and Cooking по-русски

Неофициальный русификатор модов для **Lunchtime Cozy Create and Cooking 2.6.0**, Minecraft 1.20.1 и Forge.

[Скачать ресурс-пак](https://github.com/xeueyysq/Lunchtime-Russian/releases/download/v2.6.0/Lunchtime-Russian-2.6.0.zip) · [Страница релиза](https://github.com/xeueyysq/Lunchtime-Russian/releases/tag/v2.6.0) · [Оригинальная сборка](https://www.curseforge.com/minecraft/modpacks/lunchtime-cozy-create-cooking/files/9716665)

1. Откройте папку Minecraft профиля Lunchtime и поместите ZIP в `resourcepacks`.
2. В настройках языка выберите **Русский (Россия)**.
3. Включите ресурс-пак Lunchtime в настройках игры. Если активны другие русификаторы, поднимите Lunchtime выше них в списке.

Ресурс-пак содержит 30 880 записей в 196 языковых файлах. Среди них названия предметов, блоков и профессий, подписи интерфейсов и подсказки. Квестовая книга сборки, путеводитель Мисо и страницы книг Patchouli в этот выпуск не входят. Некоторые подписи, например сообщения редакторов Lunch Worlds, заданы в коде модов.

Часть перевода подготовлена локальной моделью. При проверке сверили ключи, форматы подстановок и целостность архива. Проверка в запущенной игре пока не проводилась.

Уведомления о заимствованных переводах сообщества и их лицензии включены в `CREDITS.txt` внутри архива.
